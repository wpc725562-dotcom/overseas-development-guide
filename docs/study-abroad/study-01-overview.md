## 二、典型时间线（以英语国家秋季入学为例）

| 时间 | 事项 |
| --- | --- |
| 入学前 18~24 个月 | 确定目标、考语言、规划预算 |
| 入学前 12~15 个月 | 考出语言成绩、准备文书、联系推荐人 |
| 入学前 9~10 个月 | 递交申请（多数学校集中在 10 月 ~ 隔年 1 月） |
| 入学前 6~8 个月 | 收到 offer、办签证、订住处 |
| 入学前 3 个月 | 订机票、体检、准备行装、办理手机/银行 |

> ⚠️ 各国各校时间差异很大，务必登陆申请院校官网核对 deadline。

## 三、核心 Checklist（节选）

- [ ] 确定留学国家与目标院校 3~8 所（保底 / 匹配 / 冲刺各若干）
- [ ] 明确语言考试类型与目标分数
- [ ] 准备成绩单 / 在读证明 / 学位证（含英文公证或认证）
- [ ] 敲定推荐人（教授 / 雇主 2~3 位）
- [ ] 撰写并修改 PS / CV
- [ ] 建立「院校 × deadline × 材料」追踪表
- [ ] 预留经费预算（学费 + 生活费 + 保险 + 机票）
- [ ] 签证材料盘点（见 [签证办理](study-05-visa)）
