# 申请材料与文书 · Application Materials

> 申请材料是「硬件」+「文书」的组合：硬件达标是门槛，文书决定区分度。

---

## 一、必要材料清单

- [ ] **成绩单**（中英文，学校盖章；部分学校要求 WES/CDGDC 等认证）
- [ ] **在读证明 / 毕业证 / 学位证**（含英文翻译件；毕业前用在读证明）
- [ ] **语言成绩**（雅思/托福/多邻国等，送分到学校）
- [ ] **标准化考试**（GRE/GMAT，如目标专业需要）
- [ ] **推荐信**（通常 2–3 封）
- [ ] **个人陈述 PS / 目的陈述 SOP**（按学校要求）
- [ ] **简历 CV / 履历**
- [ ] **护照复印件**
- [ ] 其他：作品集（艺术/设计类）、Writing Sample（部分文科）、面试准备

---

## 二、推荐人选择与沟通

- **选谁**：熟悉你且能具体评价的人——授课教授、科研导师、实习/雇主主管（选 2–3 类组合）。
- **怎么沟通**：提前 1–2 个月提出，附上你的简历/成绩单/目标学校清单，说明要写什么。
- **内容要点**：具体事例 > 空洞夸赞；体现你的能力、潜力、与申请方向的匹配。

---

## 三、PS 撰写框架（Why program / Why you / 未来）

| 段落 | 内容 |
|:---|:---|
| 开头 | 钩子：为什么对这个领域感兴趣（具体故事/经历） |
| 第 2–3 段 | 你的准备：课程、项目、实习、研究中体现的能力 |
| 第 4 段 | Why this program：为什么选这所学校/项目（具体到课程/教授/资源） |
| 结尾 | 未来规划 + 你将为项目带来什么 |

> 💡 要点：**具体 > 空泛**，用事例和数据说话；针对每所学校微调 Why program 段落。

---

## 四、CV 要点（英文简历）

- 一页为主（经历丰富可两页），倒叙排列。
- 结构：Education / Experience / Projects / Skills / Awards。
- 用动词开头、量化成果（"Led a team of 5…", "Improved performance by 30%"）。
- 技术方向：附 GitHub/作品集链接（见 [简历与作品集](../career-immigration/career-03-resume)）。
