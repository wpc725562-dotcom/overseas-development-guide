# 选校与定位 · Choosing a School

> 目标：在预算和可及性约束内，选出「保底 / 匹配 / 冲刺」三档院校，并确定专业方向。

## 一、先选「地区」再选「学校」

| 地区 | 卖点 | 门槛注意事项 |
| --- | --- | --- |
| 美国 | 名校多、就业机会广 | 费用高、签证 (F-1) / OPT 政策 |
| 英国 | 学制短 (硕士 1 年)、语言环境 | 费用不低、多数无 GPA 硬线但看重本科背景 |
| 加拿大 | 毕业后可走 PGWP 工签 → 移民路径成熟 | 移民分制 (CRS / PNP) |
| 澳大利亚 | 学签宽松、气候适宜 | 生活成本高、部分专业受 EI/配额影响 |
| 新加坡 | 离国内近、双语环境、就业友好 | 院校少、竞争激烈 |
| 中国香港 | 离国内近、国际化、学制短 | 生活成本高、住宿紧张 |
| 欧洲（德/法.荷等） | 免学费或低学费（公立） | 需语言（如德语/法语）或英语授课名额 |

> 提示：先想清楚 「毕业之后就地就业/移民」还是「回国发展」——这直接影响选校策略。

## 二、选校三步法

1. **列候选库**：按国家 → 专业排名 → 综合排名 → 就业口碑，挑 8~15 所。
2. **分层**：保底 2~3 ＋ 匹配 3~5 ＋ 冲刺 2~3。
3. **对比约束**：学费生活费预算、语言要求（是否需 GRE/GMAT）、deadline、奖学金机会。

## 三、预算快速估算（单位：当地货币 / 年）

- 学费：本科 vs 硕士，公立 vs 私立差异巨大，以官网为准。
- 生活费：（住宿 / 饮食 / 交通 / 通讯）= 地区 × 城市 standard 差异。
- 其他：保险、签证费、机票、体检公证。

> 💡 建议：把总预算做成表格，预留 10~20% buffer。
