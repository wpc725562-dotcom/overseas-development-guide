# 核心 Checklist · Core Action Checklist

> 全流程总清单。把每条目标达成后打勾，作为个人进度追踪。

## 阶段 0：决策
- [ ] 写下「为什么要出国」（至少 3 条理由）
- [ ] 选定目标地区 / 国家
- [ ] 制定整体预算上限
- [ ] 决定走留学 / 求职 / 移民哪条主线

## 阶段 1：留学主线
- [ ] 语言考试出分（雅思 / 托福 / 多邻国等）
- [ ] 完成选校名单（保底/匹配/冲刺）
- [ ] 准备齐全申请材料（成绩单/推荐信/PS/CV）
- [ ] 递交申请并追踪 deadline
- [ ] 收到 offer 后确认学校 / 定金 / 住宿
- [ ] 办签证
- [ ] 订机票 / 体检 / 行装

## 阶段 2：求职移民主线
- [ ] 英文简历 + LinkedIn 完善
- [ ] 明确岗位方向与技术栈
- [ ] 确认目标岗位是否提供工签担保
- [ ] 投递（渠道 + 内推）并建追踪表
- [ ] 面试准备（技术 + behavioral）
- [ ] 谈 offer / 签证担保确认
- [ ] 办理工作签证

## 阶段 3：落地生活
- [ ] 居留登记 / 报到
- [ ] 手机 + 网络 + 银行开户
- [ ] 保险（医保 / 学校或公司险）
- [ ] 租房合同与押金
- [ ] 税务 / 社保身份确认
