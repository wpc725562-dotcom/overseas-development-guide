# 🇯🇵 日本 · 人文知识·国际业务签证 / 证书 / 求职平台 / 语言条件

> 适用：想去日本从事技术、翻译、国际业务等白领工作的你。**最常用签证是「技术・人文知识・国际业务」(一般简称“人文签”或“技人国”签证)**。

---

## 一、签证类别速览

| 在留资格 | 英语全称 | 主要适用场景 |
| --- | --- | --- |
| **技术・人文知识・国际业务** | Engineer / Specialist in Humanities / International Services | 日企技术岗、翻译员、国际业务员等最常用 |
| 特定技能 | Specified Skilled Worker | 部分行业、蓝领工种 |
| 高度人才签 | Highly Skilled Professional | 打分足够的技术人才 |

> 对“去日本工作的中文技术人员”来说，**第一选择基本是「技术・人文知识・国际业务」签证**，下文以此为主。

## 二、签证条件

### 核心条件
- **有日本雇主录用你**，且该岗位难以雇到日本人/永住者 → 雇主向出入国在留管理庁为外国人申请「在留資格認定証明書 (COE)」。
- **学历 / 经验**：① 大学（4年）相关专业毕业；**或** ② 累计 10 年以上相关实务经验（国际业务类为 3 年）。IT、外语、贸易等岗位最贴近。
- **语言**：签证本身**没有“日语 N几”的硬性规定**，但实质取决于雇主/岗位要求。多数日企技术岗要求日语 **N2 左右**，部分纯技术岗 **N3 起**，英文岗位可放宽。

### ⚠️ 2026 年新政（已联网核验 · 2026-04-15 起生效）
> 来源：出入国在留管理庁官方页 `moj.go.jp/isa/applications/status/gijinkoku.html`

- **适用对象**：申请类别第 3、4 类，且岗位属于**「翻译/口译」「客户服务（如酒店前台）」等主要使用语言技能**的职位。
- **新要求**：需提交「附属组织代表声明表」+ **语言能力证明（CEFR B2 相当）**。
- **CEFR B2 达标方式（官方列明）**：日语 **JLPT N2 及以上** ／ BJT 商务日语 **400 分以上** ／ 日本大学毕业 等。
- ✅ **对你的意义**：你是**信息安全/IT 技术岗，不属于语言类岗位**，不受该新政影响——**技术岗仍是「本科 or 10 年经验」+ 雇主 COE 为主**。但若岗位涉及客户沟通、或将来转语言岗，需要 N2 以上证明。

### 申请流程
1. 雇主在日 → 向地方出入国在留管理支局申请 **COE（在留資格認定証明書）**。
2. COE 发给你 → 你在海外（国内）持 COE 去**日本驻华使领馆**确认“在留”签证。
3. 入境日本时持 COE 换取「在留卡」。

> COE 通常由公司财务/法务代办；**你主要准备材料**：护照、照片、学历证明、履历书。

### 官方入口所在地（已联网核验 · 2026-08）
- **在留資格認定証明書 (COE)**：由**雇主**向出入国在留管理庁申请；官方说明页：`https://www.moj.go.jp/isa/applications/status/gijinkoku.html`
- **签证盖章**：日本驻华使领馆。你在广东 → 属**日本国驻广州总领事馆**领区（广东/广西/福建/海南/湖南等）。
- **签证费（广州领馆，2026-07-01 起）**：单次签证 **715 元**；数次签证 **1430 元**；再入国许可有效期延长 145 元。（另需代理机构手续费，来源：广州领馆官网 `guangzhou.cn.emb-japan.go.jp` 2026-06-25 公告）
- 官方资料来源：出入国在留管理庁 `www.isa.go.jp`、日本法务省 `www.moj.go.jp`、日本驻广州总领事馆 `www.guangzhou.cn.emb-japan.go.jp`

## 三、常见岗位与语言

| 岗位 | 主要语言要求（参考） |
| --- | --- |
| 软件工程师 / IT | 日语 N2~N3 常见；部分英文岗位可 N0/N1+English |
| 翻译 / 展会陪同 | 中文 ↔ 日语，N1 偏优 |
| 贸易 / IT事务 | N2+ 常用 |

> 语言策略：**纯技术岗 N2 起步即可**；翻译 / 客户面向岗位日文（N1）+ 英文越全越佳。英日双语是明显加分项。

## 四、日本求职平台清单

| 平台 | 适合的人 | 是不是要日语 |
| --- | --- | --- |
| **LinkedIn** | 外企 / 技术岗，英文友好 | 英文够即可起步 |
| **daijob / jobs in Japan** | 国际化企业、可跨境协助 | 有中英日任一 |
| **Indeed Japan** | 综合投递量大 | 日语建议 |
| **Wantedly** | 日企氛围、文化匹配 | 日语 |
| **マイナビ / リクナビ** | 日本老牌招聘、日企多 | 基本需日语 |
| **公司官网** | 直接投简历 | 看公司 |

> 入职策略：**先用 LinkedIn + daijob 中英简历打开市场**，日语水平上来后再攻日企；想进日企，日语 N2+ 是“敲门砖”。

## 五、行动 checklist

- [ ] 确认学历（本科 4 年）→ 主攻「技术・人文知识・国际业务」签
- [ ] 语言：IT 技术岗目标 **N2**（2026 新政下技术岗不强制语言证明，但 N2 仍是日企敲门砖）
- [ ] 备考 **JLPT**：中国大陆每年 7 月、12 月两场（2026 年为 7/5、12/6）；**N1/N2 报名费 550 元**（N3-N5 450 元）；报名提前约 2–3 个月且席位紧张
- [ ] 完善 LinkedIn / daijob 简历，标注「可在日本合法工作 (sponsorship 需求)」
- [ ] 找能办 COE 的日本雇主 offer
- [ ] 准备学历证明英文版（或日文翻译件），归入 COE 材料
- [ ] 签证费预算：单次 715 元（广州领馆，2026-07-01 起）
