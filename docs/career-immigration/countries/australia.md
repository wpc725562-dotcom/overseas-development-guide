# 🇦🇺 澳大利亚 · 签证 / 证书 / 求职平台 / 语言条件

> 适用：想去澳洲打工 / 移民的技术人员。**以常见的「工作签证」和「技术移民」为主线**。

---

## 一、去澳洲工作，主流三条路

> ⚠️ **2024-12 起 482 已更名**：原「Temporary Skill Shortage (482)」现为 **「Skills in Demand (subclass 482)」**，官方页面 URL 已变（见下）。

| 路径 | 签证类别 | 是否需要雇主 | 是否能转永居(PR) | 适用人群 |
| --- | --- | --- | --- | --- |
| 雇主担保工作签 | **482 (Skills in Demand)** | ✅ 需要澳洲雇主担保 | ✅ 可衔接 186/PR | 有雇主offer的技术岗最常用 |
| 独立技术移民 | **189 (Skilled Independent)** | ❌ 不需要雇主 | 本身就是 PR | 打分足够高的申请人 |
| 州担保技术移民 | **190 / 491** | ❌ 不需要雇主（需州担保） | ✅ | 有意去某州、分数略低的申请人 |

> 💡 大多数应届/技术求职者走 **482 雇主担保** 起步；分数足够再考虑直接 **189/190**。

## 二、482（Skills in Demand）雇主担保工作签证

### 谁有资格 / 条件（2026 年联网核验）
- **有澳洲雇主担保**（雇主需是认可担保人 / 有担保资质）。
- **职业在核心技能职业列表 CSOL**（Core Skills Occupation List）内，或薪资达「Specialist Skills」门槛；担保岗位与提名职业匹配。
- **经验**：通常要求 **至少 1–2 年相关全职工作经验**（多数渠道表述为 2 年 full-time relevant）。
- **语言**：主申请通常需 **雅思总分 ≥ 5.0**（Core Skills stream；或 PTE/托福同等成绩）。部分情况需技能评估。

### 申请入口
- 全程通过澳洲内政部在线系统 **ImmiAccount** 提交：`online.immi.gov.au`
- 官方页（新版 URL）：`https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/skills-in-demand-visa-subclass-482`
- 雇主先行：先在 ImmiAccount 申请担保资质 → 提名 → 签证。

### 要点
- 通常可获 1–4 年不等；符合条件可衔接 186/PR 永居。
- CSOL 列表与各职业要求会变，**必须以移民局当期 CSOL 文件为准**（含 ICT 安全类职业代码）。

## 三、技术移民 PR：189 / 190 / 491（打分制）

### 计分制要点（60 分起步门槛，分数越高越稳）
- **年龄**：25–32 岁给高分。
- **英语**：雅思/托福/PTE 单项达标即可给分（**雅思各单项 8 → 语言分最高**）。
- **学历/工作**：本科/硕士、境内/境外工作经验给分；技能评估 (skills assessment) 往往必需。

### 入口
- **技能评估**：先向指定机构（如澳洲工程协会/IT 类 ACS 等）做「职业评估」。
- **EOI 打分**：在 **SkillSelect** 系统在线填 EOI（入口在移民局官网，按指引进入）。
- **获邀后**：通过 ImmiAccount 正式提交 PR 申请。

> 189/190/491 的具体打分表、职业配额每年变化，务必查阅内政部当前文件。

## 四、求职平台（澳洲技术类）

| 平台 | 说明 |
| --- | --- |
| **SEEK (seek.com.au)** | 澳洲最大招聘网，技术岗多 |
| **LinkedIn** | 技术岗主流，含外企；建好 profile |
| **Indeed Australia** | 综合+速度快 |
| **lyst/ozjobs 等本地门户** | 补充信息源 |
| **公司官网直接投** | 大厂/咨询/银行直接走 career page |

> 主推 **LinkedIn + SEEK 两手抓**；海外求职常先投「支持雇主担保(482)」的岗位，投递前可在 JD 里看是否包 sponsor。

## 五、语言条件汇总

| 用途 | 最低要求（参考） |
| --- | --- |
| 482 临时工签 | 雅思总分 ≥5.0（单项 ≈ 4.5–5）或同等 PTE/托福 |
| 技术移民 EOI 加分 | 单项 6.0 起即可获「Competent」档分；越高分优势越大 |
| 移民(189/190) | 单项 6.0（Competent）通常是门槛，7.0+ 属 Superior |

> ⚠️ 上述为一般参考，具体以移民局综合测试（现行 **IELTS / PTE** 等任选）当期评估为准。

## 六、证书与资质清单

- 技能评估报告（PR 类通常需要，如 ACS）
- 学历学位 + 成绩单英文认证/公证
- 体检（健康检查证明）
- 无犯罪记录证明（如本地及原居）
- 雇主 Offer / 担保材料（482）
- 语言成绩单（雅思/PTE/托福）

---
## 七、行动 checklist
- [ ] 查自己提名职业是否在你的目标职业列表（含 482 和 PR）
- [ ] 定语言目标（技术岗通常雅思 6–7）
- [ ] 完善 LinkedIn + SEEK，标「Open to work for Australia」
- [ ] 争取「支持 sponsor 482」的岗位 offer
- [ ] 若走 PR：评估是否需要技能评估 + 算 EOI 分数
