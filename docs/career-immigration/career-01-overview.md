## 二、前端关键词（技术方向为例）

海外技术岗求职，需先明确方向与语言：
- 后端 / 前端 / 全栈 / 移动端 / 数据 / AI-ML / DevOps
- 对应技术栈、框架、算法（LeetCode）、系统设计（资深岗）
- 备好英文自我介绍、项目讲演 (Behavioral + Technical)

## 三、核心 Checklist（节选）

- [ ] 英文简历（若需要双语）＋ 目标岗位定制
- [ ] LinkedIn 主页完善并开启 Open to Work
- [ ] GitHub / 作品集 / 个人站点 作品沉淀
- [ ] 技术栈整理：主攻 1 个 + 副攻 1~2 个
- [ ] 算法刷题 plan（leetcode daily / contest）
- [ ] 明确工签可行性：查目标岗位所在地是否提供工作签证担保
- [ ] 简历投递与面试追踪表（公司 / 岗位 / 进度 / 结果）
