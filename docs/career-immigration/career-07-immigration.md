# 移民路径 · Immigration Paths

> 长期居留（永居 PR/国籍）的常见路径。**先搞清目标国的移民框架，再倒推自己的最优路线**。

---

## 一、常见移民路径

| 路径 | 说明 | 典型国家 |
|:---|:---|:---|
| **技术移民（打分制）** | 年龄/学历/语言/经验打分，达线申请 | 🇨🇦 Express Entry、🇦🇺 189/190/491、🇳🇿 |
| **雇主担保移民** | 雇主担保 + 工作数年 → 转永居 | 🇦🇺 186、🇬🇧、🇩🇪 Blue Card |
| **留学转移民** | 留学 → 毕业工签 → 工作 → 永居 | 🇨🇦、🇦🇺、🇳🇿 |
| **投资/创业移民** | 资金投资或创业 → 居留 | 🇸🇬、🇭🇰、部分欧洲国家 |
| **家庭团聚** | 配偶/亲属关系 | 多数国家 |
| **杰出人才** | 高成就人才快速通道 | 🇺🇸 EB-1/O-1、🇬🇧 Global Talent |

---

## 二、怎么选自己的路径（决策框架）

1. **你的硬条件**：年龄、学历、语言、工作经验、资金。
2. **目标国政策**：打分表/职业列表/薪资门槛（年年变）。
3. **时间与成本**：各路径耗时和花费差异大。
4. **倒推路线**：如「技术移民分数不够 → 先留学/先工作攒分」是常见组合。

> 你的具体测算案例见 [个人路线图](../personal/route-plan)（澳洲 189/190 分数测算）。

---

## 三、永居 PR 后

- 多数国家 PR = 自由工作 + 福利 + 无签证限制；入籍另有居住时间/语言要求。
- PR 有维持条件（居住时间等），长期离开可能失去。

---

## 四、重要提醒

- ⚠️ **移民政策复杂且变动极快**：以目标国官方移民局为最终依据。
- ⚠️ **谨慎对待中介**：可咨询，但别被「保过」话术收割（正规持牌顾问可查注册号）。
- ⚠️ **别孤注一掷**：移民是长线目标，留学/工作/移民组合路线更稳。
