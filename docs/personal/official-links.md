# 🔗 官方信息核对清单 · Official Sources Checklist

> **用法**：每一条都是你要「亲自去官方核实」的关键点。核对一项、勾一项。
> 本仓库所有文档都是参考，**签办决策只信这些官方源头**。
>
> ✅ **2026-08-20 已联网核验过的条目**（见下表格与国别文档）；未核验项仍需你自行确认。

## 🇯🇵 日本（主攻目标）

### 1. 出入国在留管理庁 / 法务省（移民/在留资格官方）
- **在留資格「技術・人文知識・国際業務」官方页（已核验，含 2026-04-15 新政）**：
  - `https://www.moj.go.jp/isa/applications/status/gijinkoku.html`
  - 确认：在留期间 5/3/1 年或 3 个月；学历 = 大学毕业 或 10 年实务经验；语言类岗位新需 CEFR B2 证明（N2 可达标）
- 官网：`https://www.isa.go.jp`
- **在留資格認定証明書（COE）** 申请流程与材料：见上述官方页

### 2. 日本驻华使领馆（你属**广州总领事馆**领区）
- 日本国驻广州总领事馆：`https://www.guangzhou.cn.emb-japan.go.jp`
- **签证费公告（已核验，2026-07-01 起）**：单次 715 元 / 数次 1430 元 / 再入国延长 145 元
  - 页面：`guangzhou.cn.emb-japan.go.jp/itpr_zh/11_000001_00871.html`
- 领区范围确认（广东/广西/福建/海南/湖南等——以官网当期为准）

### 3. JLPT 日语能力考试（报名/日期/费用）
- 官网：`https://www.jlpt.jp`
- **2026 年考试（已核验）**：**7月5日、12月6日**两场；中国大陆 **N1/N2 = 550 元，N3–N5 = 450 元**；报名提前约 2–3 个月，席位紧张（北京/上海/广州/深圳 30 分钟内抢完）
- 中国报名：`jlpt.neea.cn`（公网）/ `jlpt.neea.edu.cn`（教育网）

### 4. 日本求职相关官方/正规渠道
- 厚生労働省「外国人雇用」信息服务：`https://www.mhlw.go.jp`（政策参考）
- 各招聘平台（LinkedIn / daijob / Wantedly）非官方但可作渠道（见 [japan.md](../career-immigration/countries/japan.md)）

## 🇦🇺 澳大利亚（远期暂缓，仍记好）

### 1. 澳洲内政部 Home Affairs
- 官网：`https://www.immi.homeaffairs.gov.au`
- **482 已更名「Skills in Demand (subclass 482)」（已核验）**：官方页 `https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/skills-in-demand-visa-subclass-482`；要求含 CSOL 职业列表、雇主担保、1–2 年相关经验、雅思 ≥5.0
- **189 / 190 / 491 技术移民** 官方页面：打分表（Points table）、职业列表
- **CSOL（Core Skills Occupation List）** 当期文件——含 ICT 安全类职业代码，需自行核对当期版
- **ACS 技能评估**（IT类）：`https://www.acs.org.au`

### 2. 英语考试
- IELTS：`https://www.ielts.org`（或中国考区官网）
- PTE：`https://www.pearsonpte.com`
