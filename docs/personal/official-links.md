# 🔗 官方信息核对清单 · Official Sources Checklist

> **用法**：每一条都是你要「亲自去官方核实」的关键点。核对一项、勾一项。
> 本仓库所有文档都是参考，**签办决策只信这些官方源头**。

---

## 🇯🇵 日本（主攻目标）

### 1. 出入国在留管理庁（移民/在留资格官方）
- 官网：`https://www.isa.go.jp`
- **在留資格「技術・人文知識・国際業務」** 官方说明（条件/材料）：
  - 首页搜索「技術・人文知識・国際業務」→ 在留資格一覧页
- **在留資格認定証明書（COE）** 申请流程与材料
- **审核标准**：学历/经验（大学卒業 or 10年经验）以官方页面为准

### 2. 日本法务省
- 官网：`https://www.moj.go.jp`

### 3. 日本驻华使领馆（你属**广州总领事馆**领区）
- 日本国驻广州总领事馆：`https://www.guangzhou.cn.emb-japan.go.jp`
- 签证申请（持 COE 申请签证）官方指引页
- 领区范围确认（广东/广西/福建/海南/湖南等——以官网当期为准）
- ⚠️ **签证费用**：以领馆当期公布的签证费表为准

### 4. JLPT 日语能力考试（报名/日期/费用）
- 官网：`https://www.jlpt.jp`
- 中国报名渠道：教育部考试中心 / 各考场官网（每年 7 月、12 月考试，报名提前约 2–3 个月）

### 5. 日本求职相关官方/正规渠道
- 厚生労働省「外国人雇用」信息服务：`https://www.mhlw.go.jp`（政策参考）
- 各招聘平台（LinkedIn / daijob / Wantedly）非官方但可作渠道（见 [japan.md](../career-immigration/countries/japan.md)）

## 🇦🇺 澳大利亚（远期暂缓，仍记好）

### 1. 澳洲内政部 Home Affairs
- 官网：`https://www.immi.homeaffairs.gov.au`
- **482 (TSS) 签证** 官方页面：条件/费用/申请入口（ImmiAccount）
- **189 / 190 / 491 技术移民** 官方页面：打分表（Points table）、职业列表
- **Skilled Occupation List / 技能职业列表** 当期文件
- **ACS 技能评估**（IT类）：`https://www.acs.org.au`

### 2. 英语考试
- IELTS：`https://www.ielts.org`（或中国考区官网）
- PTE：`https://www.pearsonpte.com`
