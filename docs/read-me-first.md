# 用这个仓库之前：整体决策框架

> 出国不是目的，是手段。这一篇帮你把「为什么出去」「去哪里」「怎么去」想清楚。

## 一、先问自己三个问题

1. **我为什么要出去？**（提升学历 / 高薪工作 / 长期居留移民 / 生活体验 / 逃离现状 / 家庭因素）
2. **我想去哪个国家 / 地区？**（英语国家 / 欧洲 / 亚洲 / 澳新加）
3. **我的约束是什么？**（预算 / 语言水平 / 学历背景 / 工作年限 / 家庭 / 时间）

> 💡 把答案写下来，它决定了后面的所有路径选择。

## 二、三条路径概览

| 路径 | 门槛 | 时间成本 | 经济成本 | 终点 |
| --- | --- | --- | --- | --- |
| 出国留学 | 语言/学历/资金 | 1~4 年 | 高 | 学位 → 求职 → 工签 |
| 海外求职 | 技能/语言/经验 | 数月~数年 | 中 | 工作签证 → 永居 |
| 海外移民（技术/投资） | 年龄/学历/语言/资金 | 较长 | 高 | 直接居留权 |

三条路径不互斥，常见组合：**先留学 → 毕业后工签 → 求职 → 转永居**。

## 三、本仓库怎么用

- **板块按阶段划分**，从决策 → 准备 → 落地 → 长期，逐步推进。
- 每篇文档建议配合对应的 **Checklist** 使用，out 一条勾一条。
- 所有专业信息请以**官方原始来源**为准，仓库内的链接会尽量标注出处。
