- [ ] 入境与居留登记（报到/备案，按国别）
- [ ] 办理本地手机号 / 网络

- [ ] 住宿确认（签合同 / 交接）
- [ ] 学校 / 公司注册报到
- [ ] 保险（医保 / 学校险或公司险）
- [ ] 确认税务 / 社保 / 签证状态
